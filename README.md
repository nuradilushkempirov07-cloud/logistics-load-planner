# Logistics Load Planner

Локальная корпоративная система для расчёта загрузки транспорта и консолидации заявок.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173/`).

## Как дать доступ коллегам

Для показа на одном компьютере достаточно передать папку проекта или архив и выполнить команды выше.

Для общего доступа через интернет соберите проект командой `npm run build`, затем разместите папку `dist` на любом статическом хостинге. Настройки и расчёты сохраняются в `localStorage` каждого браузера отдельно, поэтому у каждого пользователя будет своё локальное рабочее пространство. Для совместной работы с едиными данными потребуется отдельный сервер и база данных.

## Проверка

```bash
npm run test
npm run build
```
